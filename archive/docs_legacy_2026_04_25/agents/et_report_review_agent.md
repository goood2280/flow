# ET Report Review Agent

## 목적
ET report와 ET time 결과를 묶어서, 측정 package와 seq bottleneck을 운영 관점에서 요약한다.

## 해야 할 일
- recent package 정리
- repeat lot / repeat request 확인
- seq별 active duration 확인
- seq 사이 idle gap 확인
- 어느 seq/item이 시간을 먹는지 요약

## 주요 출력
- seq timeline summary
- idle gap findings
- report highlights

## v9.0.3 — 2주 안에 고칠 것 (핫픽스)

빠른 체감 개선 위주. 각 항목 반일~1일 공수.

### 1. ML 탭 beta 로 승격

- **현상**: "PLANNED" 배지 → 유저가 안 들어감
- **어떻게**: 배지를 "BETA" 로 변경 + 안내 배너 + Home 카드에 표시
- **공수**: 반일
- **효과**: ML 기능 발견율 40%↑ 예상

### 2. Home 상단에 "3가지 질문" 섹션

- **현상**: 기능 나열 카드만 있음
- **어떻게**: "내 lot 문제있나? / plan 대로 흐르나? / 이번 주 인폼 요약?" 3개 질문 + 각각 추천 페이지 자동 이동
- **공수**: 1일
- **효과**: 신규 유저 첫 5분 이탈률 개선

### 3. 사이드바 애매 탭 4개 정리

- **현상**: WaferLayout · Messages · TableMap · DevGuide 포지션 불명
- **어떻게**:
  - WaferLayout: 용도 설명 배너 추가
  - Messages: "내부 알림함" 으로 라벨 변경
  - TableMap: admin 탭 내부로 이동 (일반 유저 숨김)
  - DevGuide: 개발자 권한 있는 유저만 노출
- **공수**: 1일
- **효과**: 일반 유저 사이드바 15탭 → 11탭, 인지부하 감소

### 4. Dashboard 색상 통일

- **현상**: `COLORS` + `PASTEL` 두 팔레트 혼재 (15색 × 2)
- **어떻게**: UXKit 에 chartPalette 로 통합 → 차트 종류별 규칙 표준화
- **공수**: 반일
- **효과**: 회의 자료 가독성 개선

### 5. SplitTable 내부 용어 은닉

- **현상**: "override-debug", "long-items", "fab-roots" 같은 엔지니어 용어가 UI 라벨
- **어떻게**: 톱니바퀴 안 "고급" 탭으로 격리 + 일반 라벨은 한국어
- **공수**: 1일
- **효과**: 신규 유저 학습곡선 개선

### 6. 제품 중복 근본 차단

- **현상**: PRODA 중복이 v9.0.0 one-shot 정리 후에도 산발 재발
- **어떻게**: 저장 시점 dedup + 매일 새벽 자동 정리
- **공수**: 1일

- 로그인 · 트래커 · 인폼 · SplitTable · 회의 · 관리자 · 대시보드 전 영역
- 커버리지 55% 목표 (현재 9%)
- **효과**: 안정성 점수 4.0 → 6.5

### 4. Meeting "이슈 가져오기" 대확장

### 5. Tracker 카테고리 대확장

기존 v9.1 로드맵 — Monitor(FAB 특정 step 알람) + Analysis(ET wafer 단위) 2 카테고리 자동 등록, wafer_id `"1-10"`/`"all"` 파싱, 하루 2회 자동 체크, 자동 완료.

### 6. 3분 온보딩 투어

신규 유저 첫 로그인 → 9 step spotlight tour (Home → Tracker → Inform → Meeting → SplitTable → Dashboard → ML → Admin → Done). 각 step 3~5줄 설명.

## v9.2 — 3개월 안에 (플랫폼화)

조직 전체가 의존하는 도구로 가기 위한 기초 체력.

| 항목 | 왜 필요한가 | 기대 효과 |
|---|---|---|
| **GitHub Actions CI** | main 깨짐 자동 감지 | 개발 속도 + 안정성 |
| **구조화 로깅 + request_id** | "어제 오후 2시 SplitTable 느렸던 이유?" 답 가능 | 장애 대응 시간 30분 → 5분 |
| **SQLite 세션 저장소** | 동시 사용자 50+ 에서도 로그인 OK | 유저 확장 무빙 |
| **Prometheus/Grafana** | 요청 latency, 에러율 실시간 | 미리 대응 가능 |
| **제품별 RBAC** | 타 부서 유저가 남의 제품 못 봄 | 보안 감사 pass |
| **비밀 암호화 + 의존성 감사** | 평문 파일 유출 방지, CVE 자동 | 보안 점수 6 → 7.5 |

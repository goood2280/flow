flow 앱(/mnt/d/TEST_Making_Video/semi_all/flow)의 SplitTable 산만함을 다음 4가지 영역에서 정리해. 모두 한 task 에서 처리.

[현 문제]
1. SplitTable view (앱 화면) + 인폼 메일 캡처 좌상단 첫 헤더 cell 에 root_lot_id 값과 lot_id 값들이 한꺼번에 적혀 산만하다. 예: 첫 cell 에 'root_lot_id A1003 / lot_id A1003A.2, A1003A.3, A1003B.2, A1003C.1, A1003C.2'.
2. 인폼 메일 캡처: wafer 25개가 12개씩 chunk 로 분할되고 각 chunk 위에 root_lot_id 헤더가 반복돼 메일 본문이 세로로 길게 잘린다.
3. SplitTable 좌측 검색 폼의 라벨이 '제품 / 루트 Lot ID / Fab Lot ID / Wafer ID' 처럼 한국어/영어 혼용이라 SplitTable 헤더 컬럼명(root_lot_id, lot_id, wafer_id)과 매칭이 안 보인다.
4. PRODUCT 셀렉트 박스 옵션 표시명에 'ML_TABLE_' prefix 가 그대로 노출돼 'ML_TABLE_PRODA' 처럼 보인다.

[원하는 결과]
1. 첫 헤더 cell 은 행 라벨만(예: 'root_lot_id', 'lot_id', '항목'). 값은 같은 행의 옆 cell 에 colspan 으로.
2. 메일 캡처 wafer 25개는 한 table 한 행에 가로로 모두 펼쳐지고, 표 wrapper 에 overflow-x:auto 적용. chunk 분할 + root_lot_id 헤더 반복 제거.
3. 검색 폼 라벨을 영문 대문자로 통일: 'PRODUCT' / 'ROOT LOT ID' / 'LOT ID' / 'WAFER ID'. (placeholder 는 기존 그대로 유지하되 라벨만 변경.)
4. PRODUCT 셀렉트 옵션 표시는 'ML_TABLE_' prefix 제거 후 제품명만 ('PRODA', 'PRODB' 등). select value(서버 전송값) 는 'ML_TABLE_PRODA' 그대로 유지. stripMlPrefix() 헬퍼가 이미 있으면 재사용.

[코드 reference]
- backend/routers/informs.py: 메일 _build_html_body / _mail_split_chunks / _mail_fit_col_styles / _mail_colgroup_html (wafer chunk 12개 분할 helper)
- backend/routers/splittable.py: view JSON 응답에 첫 cell 텍스트를 합쳐 내려주면 row_labels 분리 필드로 분해
- frontend/src/pages/My_SplitTable.jsx, frontend/src/pages/SplitTable/PlanPanel.jsx: 앱 view thead 렌더 + 좌측 검색 폼
- frontend stripMlPrefix() (있으면): ML_TABLE_ prefix 축약

[작업]

A) 첫 헤더 cell 분리 (앱 + 메일 공통)
   1) 앱 SplitTable view: thead 첫 cell 에 'root_lot_id 값 + lot_id 값' echo 제거. 첫 cell 은 행 라벨만.
      - root_lot_id 행: cell A1='root_lot_id', 옆 cell 에 값 colspan.
      - lot_id 행: cell A2='lot_id', 옆 cell들에 lot_id별 colspan.
      - 항목/parameter 행: cell A3='항목' (기존 라벨), 옆 cell 들에 #1..#N.
   2) 메일 _build_html_body 내 SplitTable HTML 도 동일.
   3) backend 가 view JSON 에 첫 cell 텍스트를 합쳐 내려주면 row_labels 별도 필드로 분해해 FE 가 그리도록.

B) 메일 wafer chunk 분할 제거 (메일 한정)
   - _mail_split_chunks 등 helper 가 wafer 를 12개씩 자르면 한 chunk = 전체 wafer 로 통합.
   - colgroup 은 첫 라벨 column 1 + wafer N = N+1 columns 한 table.
   - root_lot_id 헤더 반복 제거(한 번만).

C) 메일 wrapper overflow-x:auto
   - SplitTable HTML 직전 <div style='overflow-x:auto;-webkit-overflow-scrolling:touch;max-width:100%'> wrapper.
   - 메일 본문 max-width 강제 좁게면 그 wrapper 만 해제(내부 메일 본문 max-width 는 유지).

D) 검색 폼 라벨 영문 대문자 통일 (frontend My_SplitTable.jsx 또는 검색 폼 위치)
   - '제품' → 'PRODUCT'
   - '루트 Lot ID' → 'ROOT LOT ID'
   - 'Fab Lot ID' → 'LOT ID'
   - 'Wafer ID' → 'WAFER ID'
   - placeholder/예시 텍스트는 그대로(예: 'fab_lot_id 입력', '예: 1,2,3').
   - 같은 라벨 패턴이 다른 곳(인폼 검색, dashboard 등)에도 있으면 일관성 위해 같이 정리하되 회귀 위험 클 경우 SplitTable 만.

E) PRODUCT 셀렉트 ML_TABLE_ prefix 제거 표시
   - SplitTable 검색 폼의 product select option 표시:
     <option value='ML_TABLE_PRODA'>PRODA</option>
   - select 값(서버 전송값) 은 'ML_TABLE_PRODA' 그대로 유지(회귀 X).
   - frontend stripMlPrefix() 헬퍼가 이미 있으면 재사용. 없으면 inline 으로 .replace(/^ML_TABLE_/, '').

   - frontend 검색 폼 라벨 변경/PRODUCT prefix 축약은 기존 FE 단위 테스트가 있으면 보강, 없으면 light 검증 코멘트.

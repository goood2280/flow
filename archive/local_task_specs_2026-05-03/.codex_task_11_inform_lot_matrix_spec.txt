       products: [
         {
           product: "PRODA",
           lots: [
             {
               root_lot_id: "A1001",
               modules: { "GATE": {state:"completed", inform_id:"...", checked_at:"..."},
                          "STI":  {state:"in_progress", inform_id:"...", ...},
                          ...},
               progress: {done: 5, total: 11},
               last_update: "2026-..."
             }, ...
           ]
         }, ...
       ],

   - days 기본 90, ?days 옵션. ?search 는 root_lot_id substring.
   - 권한: 모든 유저 read OK.

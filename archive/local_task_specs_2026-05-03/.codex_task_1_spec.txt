flow 앱(/mnt/d/TEST_Making_Video/semi_all/flow)에서 인폼 메일을 "랏관리팀이 단위 모듈팀(GATE/STI/PC/MOL/BEOL/ET/EDS/S-D Epi/Spacer/Well/기타)에게 plan 적용을 통보"하는 형태로 재구성해줘.

[배경]
- admin_settings.json의 inform_user_modules는 username→[modules] 매핑이다(예: "hol":["GATE","STI",...]).
- 인폼 1건은 module 필드를 가질 수 있다. 그 module의 담당 유저들에게만 메일이 자동 발송돼야 한다.
- SplitTable 캡처가 메일 본문에 첨부되는데, 모듈에 해당하는 KNOB/MASK 컬럼만 시각적으로 강조해야 한다(나머지는 평소대로).

[요구사항]

1) 모듈→담당자 reverse 매핑 (backend/routers/informs.py 또는 새 helper)
   - inform_user_modules에서 module→[usernames] 역방향 인덱스 생성 함수 추가.
   - 인폼 module 필드가 비어있으면 reverse 안 함(기존 to_users 그대로).

2) 메일 발송 라우트 보강 (POST /api/informs/{inform_id}/send-mail, mail_preview)
   - to_users가 비어있고 inform.module이 있으면 자동으로 그 모듈 담당자들의 이메일로 그룹화.
   - 사용자가 명시적으로 to_users/groups를 지정한 경우는 그대로 둔다(자동 그룹화 X).
   - mail_preview에도 동일 로직 반영.

3) 메일 자동 본문/제목 (사용자가 본문 비워둔 경우만 자동 채움)
   - 제목: lot 1개면 "[plan 적용 통보] {product} {root_lot_id} - {module}", 다수면 "[plan 적용 통보] {product} ({n}lots) - {module}".
   - 본문 첫 단락: "안녕하세요. {module}팀에 다음과 같이 plan 을 적용할 예정입니다."
   - 다음 단락: 사유(reason), 작성자(sender_username 또는 "랏관리팀"), 작성시간, lot 리스트.
   - 기존 _build_html_body 흐름과 호환되게.

4) 모듈→KNOB 컬럼 강조 매핑 신규
   - data/flow-data/inform_module_knob_map.json 신규 파일 (없으면 빈 dict로 초기화).
     예시 시드: {"GATE":["GATE_DOSE","GATE_TIME"],"STI":["STI_DEPTH","STI_CD"],"PC":["PC_DOSE"],"MOL":[],"BEOL":[],"ET":[],"EDS":[],"S-D Epi":[],"Spacer":[],"Well":[]}.
   - SplitTable 캡처 HTML 렌더링에서 inform.module에 해당하는 KNOB/MASK 컬럼은 헤더와 셀에 노란 배경(#fff7cc) + 굵은 테두리(2px solid #ca8a04). 매핑이 없거나 빈 리스트면 강조 없이 평소대로.

5) 신규 API
   - GET /api/informs/modules/recipients?module=GATE — 그 모듈 자동 수신자 목록 [{username, email}].
   - GET /api/informs/modules/knob-map — 매핑 전체 조회 (모든 유저 read OK).
   - POST /api/informs/modules/knob-map — admin 전용. 본문 {module:str, knobs:[str]}로 매핑 한 모듈 set/replace.

6) Admin UI (frontend/src/pages/My_Admin.jsx 의 인폼 섹션)
   - "모듈→KNOB 매핑" 편집 모달 또는 inline 표.
   - 모듈 dropdown(설정된 모듈 목록) + KNOB 콤마구분 입력 + 저장 버튼.

7) 테스트
   - tests/inform/test_module_wise_mail.py 신규:
     * 모듈→담당자 reverse 매핑 정확성
     * to_users 비어있을 때 자동 그룹화
     * 자동 제목/본문 포맷
     * KNOB 강조 HTML(노란 배경) 렌더 검증
     * /modules/recipients, /modules/knob-map GET/POST 검증(권한 포함)
   - 기존 인폼 메일 테스트(test_inform_lot_snapshot.py 등) 회귀 없게.

8) 빌드
   - 마지막에 python3 _build_setup.py 한 번 돌려 setup.py 재빌드.
   - frontend는 npm --prefix frontend run build 로 dist 갱신.

flow 앱(/mnt/d/TEST_Making_Video/semi_all/flow)의 대시보드를 Spotfire 풍 좌측 항목 리스트 + 우측 차트 패널 구조로 정리하고, 차트 종류별 기본 설정을 도입해 도메인 관리자가 항목 클릭만으로(또는 홈 Flowi 에 자연어로 요청만 해도) boxplot/scatter/trend/correlation matrix/wafer map 등 다양한 차트를 빠르게 띄울 수 있게 해줘. 시각적으로 첨부 이미지 reference 풍(다크 톤 + 깔끔한 axis/legend/spacing) 으로 정돈.

[배경 — 사용자 의도]
- lot 관리팀/모듈팀이 매번 차트 X/Y/group 을 일일이 설정하지 않고 그룹·항목 리스트에서 클릭만 해도 적절한 차트가 나오면 좋다.
- 한 화면에서 여러 차트를 동시에 빠르게 비교하고 싶다 (Spotfire 풍).
- "PRODA INLINE CD vs LKG scatter 그려줘" 같은 자연어 요청을 홈 Flowi 에 보내면 차트 종류 + 기본 설정을 적용해서 인라인 결과로 차트가 나와야 한다.
- 차트 종류 별로 기본 X/Y/group/color/aggregation 이 있어야 사용자가 매번 선택할 필요가 없다. admin 이 그 기본 설정을 편집할 수 있어야 한다.

[현 코드 reference — codex 가 작업 시작 전 먼저 read 해서 파악]
- backend/routers/dashboard.py — 차트 데이터 응답 라우터
- backend/routers/llm.py — Flowi 의 build_dashboard_metric_chart (line 검색)
- frontend/src/pages/My_Dashboard.jsx — 대시보드 페이지
- data/flow-data/dashboard_charts.json — 사용자 차트 정의 저장 (있으면)
- data/flow-data/dashboard_snapshots.json — 스냅샷
- backend/core/semiconductor_knowledge.py — 도메인 metric/item alias

[작업]

A) 좌측 항목 리스트 패널 (Spotfire 풍)
   ★ frontend/src/pages/My_Dashboard.jsx 상단/좌측에 새 panel.
   - 1단: 그룹 토글 — FAB / ET / INLINE / VM / EDS / KNOB / MASK / SPC. 사용자가 한 번에 한 그룹 선택.
   - 2단: 항목 리스트 — 그룹의 item/parameter list. 검색창 + virtualized scroll(항목 수 500+ 대비). 항목 옆에 source_type 배지 (FAB 파랑 / ET 핑크 / INLINE 초록 / VM 보라).
   - 항목은 단일/다중 클릭 가능 (Ctrl/Shift). 다중 선택 시 차트 type 에 따라 동작:
     * scatter: 2개 선택 → X=첫 항목, Y=둘째 항목.
     * correlation_matrix: 3개 이상 → 모든 페어 corr.
     * boxplot: 1개 선택 → X=step/category, Y=항목.
     * trend: 1~3개 선택 → X=time, Y=항목들.
   - 기본 그룹/항목 데이터는 backend/core/semiconductor_knowledge.py + product_config 에서 합성. 신규 GET /api/dashboard/items?group=ET&product=PRODA → list[{key, label, source_type, default_chart_type}].

B) 우측 차트 패널 (multi-chart grid)
   ★ My_Dashboard.jsx 우측 영역.
   - 차트 카드 grid (사용자가 +/- 로 카드 추가/삭제). 카드당 chart_type select (scatter / boxplot / trend / correlation_matrix / wafer_map / classification / stacked_bar).
   - 항목 리스트에서 클릭 시 활성 카드 (focus 상태) 의 X/Y/group 자동 채움 후 즉시 렌더.
   - 카드 우상단 ⋮ 메뉴: 기본 설정 적용 / 사용자 정의 편집 / CSV/PNG 내보내기 / 카드 복제 / 삭제.
   - 차트 라이브러리: 기존(plotly/recharts/chart.js — 어느 거든 이미 있는 것 활용). 추가 의존 X.
   - visual: 다크 톤 default + 라이트 토글. 폰트 14, axis 12, legend bottom, padding 균일.

C) 차트 종류별 기본 설정
   ★ 신규 데이터 파일 data/flow-data/dashboard_chart_defaults.json
   - 형식:
     {
       "scatter": {"x":"$item1", "y":"$item2", "color":"lot_id", "agg":"raw"},
       "boxplot": {"x":"step_id", "y":"$item1", "color":"product"},
       "trend":   {"x":"tkout_time", "y":"$item1", "group":"lot_id", "agg":"median"},
       "correlation_matrix": {"items":"$selected", "method":"pearson"},
       "wafer_map": {"value":"$item1", "agg":"median"},
       "classification": {"x":"step_id", "y":"$item1", "group":"product"},
       "stacked_bar": {"x":"step_id", "y":"count", "group":"defect_type"}
     }
   - $item1/$item2 는 사용자가 좌측 list 에서 선택한 항목들로 채워짐. $selected 는 다중 선택 list.
   - 신규 endpoint:
     * GET /api/dashboard/chart-defaults — 모든 chart_type 의 default
     * POST /api/dashboard/chart-defaults (admin only) — 한 chart_type 의 default 갱신
   - admin UI: My_Admin.jsx 또는 My_Dashboard 안의 admin 톱니에 chart_type 별 default 편집 모달.

D) 자연어 차트 요청 — 홈 Flowi 보강 (build_dashboard_metric_chart)
   ★ backend/routers/llm.py 의 build_dashboard_metric_chart 분기 보강.
   - 자연어 → chart_type 추론 keys:
     * "scatter","correlation","산점도","상관" → scatter (2 items 매칭) 또는 correlation_matrix (items >= 3)
     * "boxplot","박스","분포" → boxplot
     * "trend","추세","시계열" → trend
     * "wafer map","웨이퍼맵","2d" → wafer_map
     * "classification","분류","step별" → classification
   - chart_type 결정 후 dashboard_chart_defaults.json 의 default 적용. $item* 는 prompt 에서 추출한 item alias 로 채움.
   - 응답 shape: {chart_type, config, data, fit, stats_table, chart_session_id} — FE 가 인라인 차트로 렌더.
   - 일반 유저 호출 시: read_only 보장 (data 변경 X). admin 만 default 편집 endpoint 호출 가능.

D+) Cross-DB join 차트 (ET × INLINE × FAB × ML_TABLE)
   ★ 신규 helper backend/core/dashboard_join.py (또는 dashboard.py 확장).
   - join keys:
     * ET × INLINE: (root_lot_id, fab_lot_id, wafer_id) 기준 inner join
     * + FAB step 정보: (root_lot_id, fab_lot_id) 또는 (lot_id) 기준 left join — 특정 step_id 의 eqp_id / eqp_chamber 컬럼 매핑
     * + ML_TABLE: (root_lot_id) 기준 left join — KNOB/MASK 컬럼 매핑
   - 신규 endpoint POST /api/dashboard/multi-db-chart {primary_source, secondary_source?, x_item, y_item, product, root_lot_ids?, color_by?, group_by?, fit?, stats?, font_size?} → {data, fit_params, stats_table, panels?, chart_session_id}
   - 자연어 예시:
     * "ET LKG 와 INLINE CD scatter, FAB 24.0 SORT eqp 으로 색깔" → primary=ET, secondary=INLINE, x_item=CD, y_item=LKG, color_by="fab_step_eqp:24.0 SORT"
     * "PRODA A1003 ET PEMS_VTH ML_TABLE STI KNOB 별 컬러링" → color_by="ml_knob:STI"
     * "ET LKG eqp_chamber 별 분리해서 그려줘" → group_by="eqp_chamber:<step_id>" 패널 분리

D++) Coloring (color_by enum)
   - 'none' | 'lot' | 'wafer' | 'product' | 'fab_step_eqp:<step_id>' | 'fab_step_eqp_chamber:<step_id>' | 'ml_knob:<knob_name>' | 'ml_mask:<mask_name>'
   - 자연어 → color_by 변환:
     * "FAB <step_id> eqp 으로 색깔/컬러링" → fab_step_eqp:<step_id>
     * "<step_id> eqp_chamber 컬러" → fab_step_eqp_chamber:<step_id>
     * "KNOB <name> 에 따라 / 별 컬러링" → ml_knob:<knob_name>
     * "MASK <name> 별" → ml_mask:<mask_name>
     * "lot 별 색" → lot
   - color_by 가 null/none 이면 단일 색.

D+++) Fitting + R² (선택)
   - fit enum: 'none' | 'linear' | 'quadratic'
   - 자연어 keys: "1차 피팅","fitting","linear","R2","R²","2차" → fit 결정
   - 응답에 fit_params {slope, intercept, r2, equation:"y = a*x + b", residual_std} + chart 위에 라인 + 우상단 R² 텍스트
   - chart_type=scatter 일 때만 적용. boxplot/trend 는 기본 X (사용자 명시 시만).

D++++) Group-by 다중 패널
   - group_by enum: 'eqp:<step_id>' | 'eqp_chamber:<step_id>' | 'wafer' | 'lot' | 'product' | 'knob:<knob_name>' | 'mask:<mask_name>'
   - 결과: panels list — 각 group 값별 분리된 sub-chart. FE 는 panels 를 grid 로 렌더(2 column default, 패널 수 < 4 면 1 row, 4+ 면 2 row 이상).
   - 자연어 keys: "<dim> 별로 나눠서 / 분리해서 그려" → group_by=<dim>

D+++++) Statistical table (사용자 선택 가능)
   - 차트 밑 statistical table.
   - columns enum: 'count','median','avg','min','max','std','q1','q3'
   - default columns: ['count','median','avg','std']
   - 자연어 keys:
     * "median 과 avg 만" → columns=['median','avg']
     * "count median 만" → columns=['count','median']
     * "통계표 빼" → stats=null (안 그림)
   - 응답 stats_table 형식: [{group?, count, median, avg, ...}]

D++++++) 차트 스타일 조작 (자연어 multi-turn)
   - chart_session_id 기반 stateful 수정. 이전 차트 컨텍스트 유지.
   - 자연어 keys:
     * "글씨 키워줘 / 글자 키워" → font_size +2 (default 14 → 16, max 22)
     * "글씨 줄여" → font_size -2 (min 10)
     * "축 라벨 키워" → axis_label_size +2
     * "범례 빼" / "legend 숨겨" → legend=false
     * "다크/라이트" → theme 토글
     * "y축 log" → y_scale="log"
     * "타이틀 'X 영향도' 로 바꿔" → title="X 영향도"
   - 신규 endpoint POST /api/dashboard/chart-refine {chart_session_id, action, value?} → 갱신된 chart config + data
   - 세션 저장: data/flow-data/dashboard_chart_sessions/<session_id>.json (TTL 1h, lazy eviction).
   - 세션 shape: {session_id, username, chart_type, config, base_data_query, refined_at, history:[{action,value,at}]}
   - FE: My_Home.jsx FlowiResult 가 chart_session_id 를 받으면 차트 카드 우상단에 "수정 요청" 버튼 표시. 사용자가 다음 prompt 보낼 때 그 chart_session_id 가 자동 동봉.

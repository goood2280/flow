flow 앱(/mnt/d/TEST_Making_Video/semi_all/flow)의 권한 가드 매트릭스를 backend/FE 양쪽 정밀 검토하고 누수를 fix해줘. "권한 없는 작업은 일반 유저 측에서 시도조차 못 하고, 시도되더라도 backend 가 단호하게 차단" 이 목표.

[배경 — 사용자 의도]
- 일반 유저(role!=admin)는 admin 전용 기능을 UI 에서도 호출 시도할 수 없어야 한다.
- 어떤 경로(직접 API 호출, 다른 탭 우회 등)로도 admin 전용 변경이 절대 통과하지 않아야 한다.
- 현재 backend require_admin/is_page_admin/Depends(current_user) 가 14 라우터 90회, FE role==='admin'/isAdmin 분기가 12 페이지 192회 있다. 누수 위험 높다.
- 이전 task #1~5, #3 push 후 신규 라우터 (/api/informs/modules/*, /api/dashboard/multi-db-chart, /api/dashboard/chart-refine, /api/agent/*, /api/llm/flowi/inform/walkthrough/*) 도 모두 매트릭스에 포함.

[현 상태 — 작업 시작 전 codex 가 직접 grep 해서 매트릭스 만들어]
- backend: backend/routers/{admin,agent,calendar,dbmap,filebrowser,groups,informs,llm,messages,monitor,s3_ingest,semiconductor,tracker,waferlayout,splittable,dashboard,catalog,ettime,home,ml,reformatter,session_api,auth,meetings,mail_groups,informs_extra}.py 의 모든 @router.{get,post,put,delete,patch} 데코레이터 + 의존성 함수 추출.
- FE: pages/My_*.jsx 에서 admin 분기 조건 + 그 분기 안에서 호출하는 API 경로 추출.
- 매트릭스 형태(보고용 docs/permission_matrix.md):
  | endpoint | method | backend gate | FE caller(file:line) | FE gate | risk |

[작업]

A) 매트릭스 작성 (보고)
   - docs/permission_matrix.md 신규.
   - 각 endpoint 를 표 한 줄로. risk = {ok | leak_be_open(backend gate 없는데 FE에서 admin only) | leak_fe_open(FE에서 일반 유저에게 노출되는데 backend admin-only) | inconsistent}.
   - 매트릭스 끝에 risk 별 카운트 요약.

B) 누수 fix (코드)
   1) leak_be_open: backend 에 require_admin 또는 is_page_admin 의존성 추가. 단 "조회만 admin 표시"인 페이지면 read 는 모든 유저, write 만 admin 로 분리.
   2) leak_fe_open: FE 에서 해당 버튼/메뉴/탭을 user.role!=='admin'일 때 hide. 잠금 아이콘 + 툴팁 "관리자만 사용 가능" 도 OK.
   3) inconsistent: backend gate 정책이 옳다고 가정 — FE 를 backend 에 맞춰 정렬.

C) 페이지 단위 admin 위임(is_page_admin) 정합성

   - require_admin 과 is_page_admin 의 사용 위치를 docs/permission_matrix.md 의 같은 표에 함께 표시.

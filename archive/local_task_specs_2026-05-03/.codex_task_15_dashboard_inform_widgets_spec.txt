[원하는 결과 — 차트 12종 + 라이브러리 UI]

A) 백엔드 — 인폼 데이터 dashboard 어댑터.
   - 신규 GET /api/informs/dashboard-data?metric=&groupby=&period=&product=&module= →
     응답 {points: [{x, y, series, color}], series_order: [...], meta: {...}}
   - metric (집계 대상):
     * count           — 인폼 row 카운트
     * resolution_rate — completed / total 비율
     * first_reply_h   — 첫 답글까지 시간 (hour 평균/median)
     * mail_rate       — 메일 발송된 인폼 비율
     * attach_rate     — 첨부 있는 인폼 비율
     * pending_age     — 미해결 인폼의 경과 시간 (hour)
   - groupby (X 축 차원):
     * module / product / root_lot / fab_lot / author / status / date_day / date_week / date_month / hour_of_day / day_of_week
   - period: all (default) / 7d / 30d / 90d (사용자 직언 5차 — 기본 전체).
   - product / module: 추가 필터 (옵션).
   - in-memory cache TTL 60s (dashboard 재로드시 부담 줄이기).

B) 백엔드 — dashboard chart cfg 에 source="inform" 분기 추가.
   - dashboard.py 의 차트 렌더 분기 (L1797 부근 chart_type 분기) 위에 source 분기.
   - cfg.source == "inform" 이면 db/parquet 대신 (A) 의 endpoint data 사용 (또는 직접 호출).
   - 기존 source (db/file) 회귀 X.

C) 프론트엔드 — 인폼 차트 카탈로그 12종 (preset 정의).
   각 preset = {id, label, chart_type, source:"inform", metric, groupby, default_filters, color_strategy, default_size}.

   1. **모듈별 인폼 카운트** (bar) — metric=count, groupby=module, 모듈 고정 색.
   2. **일별 인폼 추이** (line) — metric=count, groupby=date_day, series=optional(module).
   3. **제품별 인폼 분포** (donut) — metric=count, groupby=product.
   4. **상태별 일별 분포** (stacked bar) — metric=count, groupby=date_day × status.
   5. **랏×모듈 매트릭스 미니** (heatmap) — metric=count, x=module y=root_lot (top 20 lots).
   6. **응답 시간 분포** (binning) — metric=first_reply_h, x=hours bucket(0-1/1-4/4-24/24-72/72+).
   7. **처리율 추이** (line) — metric=resolution_rate, groupby=date_day.
   8. **작성자별 인폼 top10** (pareto) — metric=count, groupby=author, top 10 desc.
   9. **활동 heatmap** (heatmap) — metric=count, x=hour_of_day y=day_of_week.
   10. **모듈×제품 카운트** (heatmap) — metric=count, x=module y=product.
   11. **첨부/메일 발송률** (donut) — metric=attach_rate + mail_rate (옵션 toggle).
   12. **오래된 미해결 인폼** (table) — pending 인폼 desc by age, columns: root_lot/fab_lot/모듈/작성자/경과시간/제목.

D) 프론트엔드 — 차트 라이브러리 UI.
   - 대시보드 페이지 상단 (또는 좌측 panel) 에 "+ 인폼 차트 추가" 버튼 신설.
   - 클릭 → 모달 또는 drawer 로 12종 카드 grid (4 column) 표시.
   - 각 카드: 차트 thumbnail + 라벨 + 1줄 설명 + "추가" 버튼.
   - 추가 버튼 클릭 → 그 preset 으로 신규 차트 cfg 생성 → 대시보드 layout 의 다음 빈 자리에 삽입 → 자동 저장.
   - 사용자가 cfg 를 수정하면 (groupby/metric/period 변경) 일반 dashboard 편집 UI 로 가능.
   - 기존 dashboard 차트 추가 흐름 (db/file source) 도 그대로 유지 — 두 흐름 공존.

flow 앱(/mnt/d/TEST_Making_Video/semi_all/flow)의 인폼 페이지(My_Inform.jsx) 를 에이전트 탭처럼 깔끔하게 재구성. 상단 탭 strip + 각 탭 안에서 위 필터 + 아래 list 단순 layout. 좌우 split / vertical split 같은 복잡한 구조 X.

[배경 — 사용자 의도]
- 현재 페이지가 매트릭스+요약+list+로그+detail 다 한 화면에 섞여 너무 복잡함.
- 에이전트 탭(My_Diagnosis)처럼 상단 탭으로 카테고리 분리 + 각 탭은 위 필터 + 아래 list 단순 구조여야 함.
- 인폼은 수정/삭제 다 가능, 모든 변경은 활동 로그에 자동 기록.

[원하는 레이아웃 — 단순 탭 전환]
페이지 상단:
  ┌──── 탭 strip ─────┐
  │ 인폼 │ 로그 │ 매트릭스 │ 모듈 요약 │
  └────────────────────┘

페이지 본문(선택된 탭만):
  ┌─── 위 필터 chip (제품 / 모듈 / lot / 상태 / 기간) ───┐
  └────────────────────────────────────────────────────────┘
  ┌─── 아래 list (탭별 다름) ───────────────────────────┐
  │ 카드/표 row 들이 주르륵 보임                          │
  └────────────────────────────────────────────────────────┘

- 좌우 split X. 좌측 column 없음. 단일 column 에 위 필터 + 아래 list.
- 매트릭스 / 모듈 요약은 다른 탭. 한 화면에 같이 보이지 마.
- detail 은 row 클릭 시 drawer 또는 modal (인라인 펼침 가능).
- 5-step wizard 는 우상단 + 버튼 → 모달.

[탭별 내용]

탭 1: 인폼 (default)
   - 위 필터 chip: 제품 multi / 모듈 multi / 상태 multi / lot 검색(substring 디바운스) / 기간(7/30/90/직접) / "필터 초기화" 버튼.
   - 아래 list: 인폼 카드/표 토글, virtualized scroll, 카드 row 64px, 컬럼(제품, root_lot, fab_lot, 모듈, 상태, 작성자, 시간, ✉️·💬·📎 카운트).
   - row 클릭 → 우측 drawer 슬라이드(폭 480px) 또는 inline 펼침. drawer 안에 task #8 의 5탭(본문/메일/댓글/이력/첨부).
   - 수정/삭제: drawer 헤더에 "수정"/"삭제" 버튼. 권한(작성자 또는 admin) 만 활성. 변경 시 활동 로그에 자동 기록.
   - 빈 상태: "조건에 맞는 인폼이 없어요".

탭 2: 활동 로그 (audit)
   - 위 필터 chip: 동일(제품/모듈/lot/기간) + type 필터 (상태변경/메일/댓글/수정/생성/삭제).
   - 아래 list: 시간순(desc) audit row 들. 각 row — 시간 / 유형 아이콘+색 / 제품·lot pill / 모듈 pill / 작성자 / 요약.
   - row 클릭 → 그 inform_id 의 detail drawer + "이력" 탭 자동 활성.
   - 신규 GET /api/informs/audit-log?products[]&modules[]&lot_search&days&types[].
   - 인폼 수정/삭제 시 자동으로 audit row 추가.

탭 3: 매트릭스 (task #11 그대로)
   - 위 필터 chip: 제품/모듈/lot/기간.
   - 아래 매트릭스: 제품 그룹 헤더 + 행: lot, 열: 모듈, 셀 색(completed/in_progress/received/pending/없음) + 진행도 bar.
   - 셀 클릭 → 그 (lot, module) 인폼 detail drawer.
   - 매트릭스 endpoint(GET /api/informs/lot-matrix) 그대로 활용.

탭 4: 모듈 요약 (task #8 모듈별 progress)
   - 위 필터: 기간만.
   - 아래 카드: 각 모듈(GATE/STI/...) 별 받음/완료/진행중/대기 카운트 + 작은 progress bar + 클릭 시 인폼 탭으로 이동(필터 자동).
   - GET /api/informs/modules/summary 활용.

[필터 chip 동기화]
- 4 탭 공통 필터 (제품/모듈/lot/상태/기간) 는 같은 state. 탭 전환 시 필터 유지.
- URL query param 에 저장(공유 가능, 새로고침 유지).
- 활성 필터 chip 옆 ✕ 버튼 개별 해제.

[인폼 수정/삭제 + audit log]
- POST /api/informs/{id}/edit (또는 PUT) — 작성자 또는 admin 만. 변경된 필드만 patch.
- DELETE /api/informs/{id} — 작성자 또는 admin 만. soft-delete (실제는 deleted=true 표시, 매트릭스/list 에서 제외, audit log 에는 deleted 이벤트 기록).
- 모든 mutation(create/edit/delete/status_change/comment/mail) 은 backend 가 자동으로 audit log 에 한 row 추가.
